# 🚀 LazyTest AI Extension

**Stop grinding through boring tests—let AI do the heavy lifting.**

LazyTest AI is a modern Chrome extension designed to turn tedious online assessments into a fast, painless experience. Instead of manual searching or constant tab-switching, this extension "reads" the page context, highlights the correct answer, and explains why—all without leaving your tab.

---

## ✨ Key Features

* **Instant Extraction:** Automatically captures questions and multiple-choice options directly from your active browser tab.
* **Smart Highlighting:** Uses AI to analyze the options and pinpoint the correct choice instantly.
* **Concise Explanations:** Don't just guess. Get a brief, logical breakdown of the answer to help you learn (or just feel confident).
* **Native Side Panel UI:** Integrated directly into the **Chrome Side Panel** for a clean, non-intrusive workspace that doesn't overlap your test.

---

## 🛠 Tech Stack

* **Manifest V3:** Built using the latest, most secure Chrome extension standards.
* **Side Panel API:** Provides a native, pinned interface for a seamless user experience.
* **JavaScript:** Lightweight and optimized for fast DOM processing.
