# LazyTest AI Extension

Chrome extension for analyzing test question quality directly in the browser.

## Features
- Extracts question and answer options from the current page
- Opens analysis in Chrome Side Panel
- Evaluates question clarity and answer quality
- Provides AI-generated feedback

## Status
MVP in progress

## Tech
- Chrome Extension Manifest V3
- JavaScript
- Side Panel API

## Notes
This repository contains only the browser extension code.
